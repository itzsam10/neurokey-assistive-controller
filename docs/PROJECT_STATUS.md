# Project status

## Stage 1: hardware and signal validation

Initial jaw-EMG waveform observation and threshold experiments have been completed. The current objective is to repeat the measurements across electrode placements and sessions, quantify false triggers, and obtain comparable eye-movement EOG recordings.

### Next evidence to publish

1. Photographs and exact model names of the available boards and components
2. First labelled jaw-EMG waveform and threshold plot
3. Horizontal and vertical EOG waveforms
4. Notes describing electrode placement and recording conditions
5. Repeated event-detection and idle false-trigger results
6. Standalone embedded detection demonstration

No detection accuracy or product-performance claim will be made until it has been measured over repeated trials.
